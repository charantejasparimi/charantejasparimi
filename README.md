## About Me

Full-stack engineer based in **Chennai, India**, working as a **Junior Software Engineer at [Saptang Labs](https://www.linkedin.com/in/charantejasparimi/)**. I build AI-powered products end to end: **Python/FastAPI** and **Node.js** backends, **React/TypeScript** frontends, and **LLM features** such as **RAG pipelines** and **agents**.

I'm the builder of **[upfound.in](https://upfound.in)**, an AI-powered startup platform with **2.5K+ signups**, and I published research on plant disease detection with CNNs (IC4S 2024).

## 🔥 What I Do

- 🤖 **AI & LLMs:** RAG, GraphRAG, hybrid (keyword + vector) retrieval, LLM agents with tool calling, LLM-based entity extraction, LangChain, OpenAI SDK, ChromaDB, ArangoDB
- 🛠️ **Backend:** FastAPI, Django, Node.js/Express, REST and GraphQL APIs, Celery, RabbitMQ, microservices, OAuth
- 💻 **Frontend:** React, TypeScript, Redux, TanStack Query, Tailwind CSS
- 🗄️ **Data:** PostgreSQL, MongoDB, Redis, SQL
- ☁️ **Cloud & DevOps:** AWS, Docker, Jenkins CI/CD, Git
- 🧪 **Testing:** Jest, React Testing Library, pytest
